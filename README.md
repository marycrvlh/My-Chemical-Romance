# 🖤 My Chemical Romance — Fan Website

> Um projeto de **Front-End** desenvolvido para apresentar a história, os integrantes, a discografia e a trajetória de uma das bandas mais marcantes do rock alternativo: **My Chemical Romance**.

---

## Sobre o projeto

Este projeto consiste em uma página web dedicada à banda **My Chemical Romance (MCR)**, criada com o objetivo de reunir informações sobre sua história e apresentar sua trajetória musical de uma forma visual, organizada e interativa.

A página explora diferentes aspectos da banda, incluindo seus integrantes, principais álbuns, músicas e momentos importantes de sua carreira.

Além de ser uma página informativa, o projeto também foi desenvolvido como uma oportunidade para praticar conceitos de **desenvolvimento Front-End**, organização de conteúdo, estilização e criação de uma experiência visual inspirada na identidade da banda.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

* **HTML5** — estrutura e semântica da página
* **CSS3** — estilização, layout e identidade visual
* **JavaScript** — interatividade e funcionalidades da página

---

## 🎨 Design

A identidade visual do projeto foi inspirada na estética característica do **My Chemical Romance**, utilizando uma abordagem mais sombria e elementos visuais relacionados ao estilo da banda.

O objetivo foi criar uma interface que não apenas apresentasse informações, mas também transmitisse parte da atmosfera e personalidade associadas ao MCR.

---

## 📚 Objetivos do projeto

Este projeto foi desenvolvido com fins **educacionais**, tendo como principais objetivos:

* Praticar desenvolvimento Front-End;
* Aplicar conceitos de HTML, CSS e JavaScript;
* Trabalhar com organização e hierarquia de conteúdo;
* Desenvolver uma identidade visual para uma página temática;
* Aprimorar conhecimentos de layout e responsividade;
* Criar um projeto para compor o portfólio de desenvolvimento.

---

## 📱 Responsividade

O projeto foi pensado para proporcionar uma boa experiência em diferentes tamanhos de tela, incluindo:

* 💻 Desktop
* 📱 Smartphones
* 📟 Tablets
